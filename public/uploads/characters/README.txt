ALRS - BACKGROUND CHARACTER ART
===============================

Drop character / hero images here as .png / .svg / .webp / .jpg and they will
appear in the site's arena background after the next build - no code changes.

Up to the first 3 files (sorted by name) are used, placed left / right / centre.
Name them so they sort the way you want (e.g. 01-left.png, 02-right.png).

Tips:
- Transparent PNGs work best (they are shown as full-height cut-outs).
- Use art you are licensed to use. If this folder is empty, the site falls
  back to its own original ALRS esports artwork automatically.
